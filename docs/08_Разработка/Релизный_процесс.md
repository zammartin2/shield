## 🚀 Процесс релиза

### 1. Обновление версии

Единая точка входа — `scripts/release.sh`. Скрипт сам синхронизирует **все** места, где живёт версия
(иначе `getVersion()` разойдётся с `package.json` и уронит тесты):

```bash
# Обновляет package.json, package-lock.json, fab.json и SHIELD_VERSION в src/core/FABShield.ts,
# прогоняет lint / type-check / test:coverage / build, создаёт коммит и тег.
./scripts/release.sh 1.4.2
```

Ручной эквивалент:

```bash
npm version 1.4.2 --no-git-tag-version
sed -i 's/"version": "[^"]*"/"version": "1.4.2"/' fab.json
sed -i "s/const SHIELD_VERSION = '[^']*'/const SHIELD_VERSION = '1.4.2'/" src/core/FABShield.ts

# Создание тега
git tag -a v1.4.2 -m "Release v1.4.2"
```

---

### 4. Публикация

**Обязательный шаг** — отправка в `origin` (GitHub):

```bash
git push origin main
git push origin v1.4.2

# Проверка, что тег ушёл
git ls-remote origin refs/tags/v1.4.2
```

После пуша запускается пайплайн GitHub Actions (lint → typecheck → test → build) — релиз считается
выпущенным только после зелёного прогона.

**Необязательно** — публикация в реестры (в 1.4.0 не выполнялась):

```bash
npm publish                                   # npm
npm publish --tag beta                        # npm, бета-канал
npm publish --registry=https://fab.devorbit.ru # FAB Registry
npm view @fab-orbita/shield
```

## 🔄 Hotfix-процесс

### Критический баг в production

```text
1. Обнаружение бага
   ↓
2. Создание hotfix-ветки
   ↓
3. Исправление бага
   ↓
4. Тестирование
   ↓
5. Выпуск патча
   ↓
6. Деплой
   ↓
7. Обновление документации
```

---

### Создание hotfix

```bash
# Создание ветки
git checkout main
git pull origin main
git checkout -b hotfix/1.0.1

# Исправление
# ... внесите изменения ...

# Коммит
git add .
git commit -m "hotfix: fix critical security issue"

# Тестирование
npm run test
npm run build

# Релиз
npm version patch
git push origin hotfix/1.0.1

# Создание PR
# ... создайте PR в main ...

# После мержа
git checkout main
git pull origin main
git tag -a v1.0.1 -m "Hotfix v1.0.1"
git push origin v1.0.1
```
