## Общая модель

FAB Shield развивается по модели **Open Source Core + Commercial Cloud**.

Основная функциональность FAB Shield Core распространяется по лицензии MIT и доступна бесплатно. Коммерческая часть экосистемы включает облачные сервисы и дополнительные функции, в том числе Scout Cloud, Predictive AI и Enterprise-сервисы.

Такой подход разделяет продукт на две части:

- **FAB Shield Core** — открытый исходный код под лицензией MIT;
- **Cloud и Enterprise** — коммерческие сервисы, предоставляемые по подписке или отдельному договору.

Схожее разделение между открытым программным обеспечением и коммерческими сервисами используется в различных формах другими разработчиками инфраструктурных продуктов, включая GitLab, Redis, Grafana и Sentry. Конкретные лицензионные и коммерческие модели этих проектов могут отличаться от модели FAB Shield.

## ☁️ Коммерческие облачные сервисы

Облачные сервисы FAB Shield являются отдельной коммерческой частью экосистемы и не изменяют условия лицензирования FAB Shield Core.

### Scout Cloud

| Функция | Описание |
|:---|:---|
| Хранение паттернов | Облачное хранение паттернов атак |
| Глобальный Threat Intelligence | Работа с обезличенными данными, поступающими от клиентов сервиса |
| Обучение AI | Использование глобальных данных для обучения AI-моделей |
| Автоматические обновления | Получение Shield новых правил через облачную инфраструктуру |

Коммерческая модель Scout Cloud связана с эксплуатацией серверной инфраструктуры, баз данных и сети, использованием вычислительных ресурсов для AI, обеспечением безопасности сервиса и предоставлением поддержки.

---

### Predictive AI / AI 4.0

| Функция | Описание |
|:---|:---|
| Предсказание атак | Анализ данных для прогнозирования потенциальных атак |
| Поведенческий анализ | Анализ поведения пользователей и запросов |
| Нейросетевая защита | Использование нейросетевых моделей для анализа угроз |

Работа этих сервисов требует вычислительных ресурсов для обучения и выполнения моделей, хранения обучающих данных и регулярного обновления моделей.

Поэтому Predictive AI и AI 4.0 относятся к коммерческой части FAB Shield.

---

### Enterprise

Enterprise-предложение предназначено для организаций, которым требуется отдельная инфраструктура, расширенная поддержка или специальные условия эксплуатации.

| Функция | Описание |
|:---|:---|
| Приватное облако | Развертывание Scout Cloud в изолированной среде клиента |
| SLA 24/7 | Поддержка в соответствии с согласованным SLA |
| Соответствие стандартам | Возможность построения инфраструктуры с учетом требований HIPAA, PCI DSS, SOC 2 и GDPR |
| Расширенная аналитика | Пользовательские дашборды, отчеты и интеграции |
| Выделенная поддержка | Персональный менеджер и инженер |

Фактические условия Enterprise-сервиса, включая SLA, инфраструктуру, поддержку и требования к соответствию стандартам, определяются договором с конкретным клиентом.

Использование Enterprise-функций само по себе не является подтверждением соответствия информационной системы требованиям HIPAA, PCI DSS, SOC 2, GDPR или иного стандарта.

## Принципы модели

### Для пользователей

FAB Shield Core можно использовать независимо от облачной инфраструктуры DEVORBIT.

Открытая модель Core позволяет разработчикам изучать исходный код, проводить собственный аудит и использовать доступные локальные функции без обязательного подключения к коммерческому облаку.

Облачные сервисы подключаются отдельно и предназначены для функций, которым требуется централизованная инфраструктура, Threat Intelligence, вычислительные ресурсы или обслуживание со стороны DEVORBIT.

Порядок обработки, хранения, экспорта и удаления данных в коммерческих сервисах определяется условиями соответствующего сервиса и применимой политикой обработки данных.

### Для DEVORBIT

Коммерческие сервисы создают отдельный источник финансирования разработки и эксплуатации FAB Shield.

Доход от Cloud и Enterprise может использоваться для инфраструктуры, разработки, тестирования, документации, технической поддержки и дальнейшего развития продукта.

При этом лицензирование FAB Shield Core по MIT позволяет сохранить открытую базовую часть проекта.

## 📊 Позиционирование относительно других решений

FAB Shield сочетает локально доступный Core под MIT с отдельными коммерческими облачными функциями.

В исходной модели проекта используется следующее сравнение:

| Продукт | Лицензия | Cloud | Указанная цена |
|:---|:---|:---:|:---|
| FAB Shield | MIT для Core | Опционально | `$29/мес` для планируемого Pro |
| Arcjet | Проприетарная | Обязательно | `$49/мес` |
| Helmet | MIT | ❌ | `$0` |

| Akamai WAF | Проприетарная | Обязательно | Индивидуально |

Цены и условия сторонних продуктов могут изменяться. Перед использованием этой таблицы в публичных или коммерческих материалах их следует проверять по официальным источникам соответствующих поставщиков.

FAB Shield отличается от полностью облачной модели тем, что Core может работать отдельно от коммерческих сервисов. Подключение Cloud требуется только для функций, предоставляемых облачной инфраструктурой.

## Разделение лицензии и коммерческих услуг

Лицензия MIT регулирует использование и распространение исходного кода FAB Shield Core.

Она сама по себе не предоставляет право бесплатного использования отдельных серверов, API, вычислительных ресурсов, баз Threat Intelligence, технической поддержки или других услуг DEVORBIT.

Условия доступа к Scout Cloud, Predictive AI, Enterprise и другим коммерческим сервисам устанавливаются отдельно.

Таким образом, открытая лицензия Core и платная модель Cloud существуют независимо друг от друга:

- исходный код Core регулируется MIT License;
- доступ к коммерческой инфраструктуре регулируется условиями соответствующего сервиса или договора;
- пользователь может использовать Core без обязательной подписки на Cloud;
- коммерческие сервисы предоставляют функции, для которых используется инфраструктура DEVORBIT.
