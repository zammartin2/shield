## Логирование

FAB Shield может использовать логирование для отладки, мониторинга, обеспечения безопасности и анализа инцидентов.

В зависимости от конфигурации в логах могут присутствовать следующие сведения:

| Тип данных | Назначение |
|:---|:---|
| IP-адреса | Анализ запросов и защита от атак |
| Пути запросов | Отладка и мониторинг |
| Время запросов | Анализ производительности |
| Статусы ответов | Диагностика ошибок |

При использовании логирования разработчик или оператор системы должен учитывать, что отдельные записи журнала могут содержать сведения, подпадающие под требования законодательства о персональных данных.

### Настройка безопасного логирования

```typescript
const shield = new FABShield({
    logging: {
        level: 'info',
        exclude: {
            headers: ['Authorization', 'Cookie'],
            body: ['password', 'token']
        }
    }
})
```

Чувствительные заголовки и поля рекомендуется исключать из журналов, если их хранение не требуется для работы системы.
