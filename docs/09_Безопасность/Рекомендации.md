## 🔒 Основные рекомендации

### 1. Всегда используйте HTTPS

**Почему:** HTTPS шифрует весь трафик между клиентом и сервером.

```typescript
// Включение HSTS
const shield = new FABShield({
    headers: {
        hsts: {
            maxAge: 31536000,
            includeSubDomains: true,
            preload: true
        }
    }
})
```
Дополнительно:

Используйте сертификаты Let's Encrypt

Настройте автоматическое обновление

Проверяйте валидность сертификатов

### 2. Включите все security-заголовки
Почему: Security-заголовки — первая линия защиты.

```typescript
const shield = new FABShield({
    headers: {
        enabled: true,
        custom: {
            'X-Frame-Options': 'DENY',
            'X-Content-Type-Options': 'nosniff',
            'X-XSS-Protection': '1; mode=block',
            'Referrer-Policy': 'strict-origin-when-cross-origin'
        }
    }
})
```
### 3. Настройте CSP
Почему: CSP защищает от XSS атак.

```typescript
const shield = new FABShield({
    csp: {
        enabled: true,
        dynamic: true,
        directives: {
            'default-src': ["'self'"],
            'script-src': ["'self'", "'strict-dynamic'"],
            'style-src': ["'self'", "'unsafe-inline'"],
            'img-src': ["'self'", "data:", "https:"]
        }
    }
})
```
Рекомендации:

Не используйте 'unsafe-inline' без необходимости

Добавляйте только доверенные CDN

Используйте nonce для инлайн-скриптов

### 4. Включите AI-защиту
Почему: AI обнаруживает новые угрозы.

```typescript
const shield = new FABShield({
    ai: {
        enabled: true,
        anomalyDetection: true,
        threatPrediction: true,
        modules: {
            xssProtection: true,
            sqlInjectionProtection: true,
            ipReputation: true
        }
    }
})
```
### 5. Настройте Rate Limiting
Почему: Защита от DDoS и брутфорса.

```typescript
const shield = new FABShield({
    rateLimit: {
        enabled: true,
        default: {
            windowMs: 60000,
            max: 100
        },
        paths: {
            '/api/auth/login': {
                windowMs: 60000,
                max: 5
            }
        }
    }
})
```

### 11. Включите 2FA
Почему: Дополнительный уровень защиты.

В текущем API FAB Shield нет встроенного 2FA и challenge-механизма: модуля
`twoFactorCheck` и правил с `require2FA` не существует. Двухфакторную
аутентификацию реализуйте на уровне приложения (Identity-провайдер,
express-session и т.п.), а на уровне Shield ограничьте чувствительные
маршруты плагином, который блокирует запросы с незнакомых IP:

```typescript
// Ограничение чувствительных маршрутов доверенными IP
const adminGuard = {
    name: 'admin-guard',
    version: '1.0.0',
    onRequest: async (req) => {
        const trustedIPs = ['127.0.0.1', '::1', '10.0.0.10']
        if (req.path.startsWith('/admin') && !trustedIPs.includes(req.ip)) {
            return {
                block: true,
                status: 403,
                message: 'Доступ к /admin только с доверенных IP',
                reason: 'admin-ip-restriction'
            }
        }
    }
}

const shield = new FABShield({
    plugins: [adminGuard]
})
```

## 🚀 Продвинутые рекомендации
### 13. Создавайте кастомные правила
Почему: Для специфических угроз.

Кастомные правила описываются плагином с хуком `onRequest`:

```typescript
const customRules = {
    name: 'custom-rules',
    version: '1.0.0',
    onRequest: async (req) => {
        // Block specific IP
        if (req.ip === '1.2.3.4') {
            return {
                block: true,
                status: 403,
                message: 'IP заблокирован',
                reason: 'block-specific-ip'
            }
        }

        // Block specific user-agent
        if (req.headers['user-agent']?.includes('bot')) {
            return {
                block: true,
                status: 403,
                message: 'User-agent заблокирован',
                reason: 'block-specific-user-agent'
            }
        }
    }
}

const shield = new FABShield({
    plugins: [customRules]
})
```
### 14. Используйте плагины
Почему: Расширение функциональности.

```typescript
const shield = new FABShield({
    plugins: [
        {
            name: 'geo-blocking',
            middleware: (req, res, next) => {
                // Гео-блокировка
                const country = getCountry(req.ip)
                if (blockedCountries.includes(country)) {
                    res.status(403).send('Access denied')
                    return
                }
                next()
            }
        }
    ]
})
```
### 15. Настройте оповещения
Почему: Быстрая реакция на угрозы.

```typescript
const shield = new FABShield({
    monitoring: {
        alerts: {
            enabled: true,
            rules: [
                {
                    metric: 'threats_blocked',
                    threshold: 10,
                    interval: 60
                }
            ]
        }
    }
})
```

`actions`-массива (email/telegram/webhook) в конфиге нет: `rules` описывают
условия срабатывания, а доставку оповещений настройте на стороне приложения.
